# פריז 2026 · אפליקציית טיול משפחתית 🗼

אפליקציית ווב (PWA) לניהול טיול משפחתי בפריז, **27.7 – 4.8.2026**. בנויה כאתר סטטי בקובץ אחד, מתארחת ב-GitHub Pages, ומותקנת כאפליקציה על טלפוני המשפחה — כולל עבודה מלאה אופליין.

עיצוב בהשראת שילוט המטרו הפריזאי: כחול `#0B2E6B`, צ'יפים בצבעי קווי המטרו האמיתיים, עברית RTL.

## מה יש באפליקציה

- **לו"ז יומי** ל-9 ימים — כל יום עם תחנות, שעות, טיפים, טמפרטורה צפויה והתראות.
- **זיהוי "היום" אוטומטי** — האפליקציה נפתחת ישר על היום הרלוונטי בטיול.
- **קישורי ניווט** — כל תחנה נפתחת ב-Google Maps, כולל מסלולי הליכה מהדירה.
- **תחנות בחירה** — היכן שיש שתי אפשרויות, הבחירה נשמרת במכשיר.
- **"תעלומה בזמן"** — פרומפט מוכן להעתקה לכל אתר: ציד־מטמון היסטורי לילדים בסגנון "תעלומות בזמן".
- **צ'קליסט כרטיסים ומשימות** — עם סטטוס וקישורי הזמנה, נשמר במכשיר.
- **עבודה אופליין** — אחרי טעינה ראשונה הכל זמין גם בלי קליטה (מטרו, טיסה, חו"ל).

## התקנה כאפליקציה על הטלפון

הכתובת: `https://yarivtch.github.io/prs26/`

| פלטפורמה | איך מתקינים |
|---|---|
| **אנדרואיד** (Chrome) | פותחים את הכתובת ← תפריט ⋮ ← "הוספה למסך הבית" / "התקנת אפליקציה" |
| **אייפון** (Safari בלבד) | פותחים את הכתובת ← כפתור שיתוף ← "הוסף למסך הבית" |

חשוב לפתוח את האפליקציה פעם אחת עם אינטרנט כדי שהמטמון יתמלא — אחר כך היא עובדת גם אופליין.

## מבנה הפרויקט

| קובץ | תפקיד |
|---|---|
| `index.html` | כל האפליקציה — CSS, HTML ו-JS בקובץ אחד, ללא build וללא תלויות |
| `sw.js` | Service worker בשיטת cache-first לעבודה אופליין |
| `manifest.json` | הגדרות PWA — שם, צבעים, אייקונים, תצוגת standalone |
| `icon-192.png`, `icon-512.png` | אייקוני האפליקציה |
| `CLAUDE.md` | הנחיות עבודה מפורטות לעדכון האפליקציה |

## עדכון ופריסה

1. עריכות תוכן נעשות ב-`index.html` בלבד.
2. **בכל פריסה חובה להעלות את גרסת המטמון ב-`sw.js`** (`paris26-v1` ← `paris26-v2` וכו'), אחרת מכשירים שכבר התקינו ימשיכו להציג גרסה ישנה.
3. `git push` ל-`main` פורס אוטומטית ל-GitHub Pages.
4. לפני פריסה: לוודא תחביר JS תקין ושהדף נטען אופליין אחרי טעינה ראשונה.

פירוט מלא של מבני הנתונים והמוסכמות — ב-[`CLAUDE.md`](CLAUDE.md).
